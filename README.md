## Through this project, I learned more about Python programming, including:

- Applying conditional logic with if and elif

- Converts lb → kg
- Simple input/output interaction with the user

# Beginner Project 3: Interactive Patient Check-In System

## Overview  
This is my second beginner Python project. The goal was to build an **interactive patient check‑in system** that collects patient details, checks whether they are new or returning, and converts weight between kilograms and pounds.  

## Through this project, I learned more about Python programming, including:  
- Using loops (`while True`) to handle multiple patients  
- Applying conditional logic (`if/elif/else`)  
- Working with floats and conversion factors  
- Formatting output with f‑strings and rounding results  

## Features  
- Collects patient name, surname, and age  
- Asks if the patient is new or returning  
- Converts weight between **kg ↔ lb**  
- Allows multiple patients to check in until the user exits  

## Purpose  
The project was designed to help me move beyond a simple calculator and practice **interactive programming**. It demonstrates:  
- Clean code structure with comments  
- User input handling across multiple steps  
- Basic error management and unit conversion  
- Looping for repeated use without restarting the program  

This shows your growth: Project 1 was about arithmetic basics, while Project 2 introduces **real‑world interaction and data handling**.
