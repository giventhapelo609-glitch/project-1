# Python Calculator Program

Overview
This is my very first Python project. The goal was to build a simple calculator that performs basic arithmetic operations: addition, subtraction, multiplication, and division.  

Through this project, I learned the fundamentals of Python programming, including:
- Taking user input
- Using variables and data types
- Printing output to the console
- Handling errors such as invalid input

Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/), with error handling for division by zero

Purpose
The project was designed to help me understand the basics of coding in Python. It demonstrates:
- Clean code structure
- User input handling
- Basic error management
